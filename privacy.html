Privacy Policy

Procare Media Downloader · Effective date: August 10, 2026

Procare Media Downloader helps a user save photos and videos that are already available through the user's signed-in Procare family account.

Data the extension handles

The extension temporarily reads:

  • the Procare session token already stored by Procare in the active browser tab;
  • the children available to that signed-in account;
  • daily-activity responses needed to locate authorized photo and video files; and
  • the media URLs and basic identifiers needed to name and download those files.

This processing is necessary for the extension's single purpose. The session token is used only for HTTPS requests to Procare's API and is not written to extension storage.

Data stored locally

The extension stores a local list of media identifiers and download timestamps so that it can avoid downloading the same item twice. It also stores the latest download status. Users can clear this information from the extension.

Data collection and sharing

The extension developer does not collect, receive, sell, share, or remotely store user data. The extension has no analytics, telemetry, advertising, developer API, cloud storage, or license service.

Media files travel directly from the HTTPS locations supplied by Procare to the user's computer. Procare and the media-hosting providers used by Procare process those requests under their own policies.

Retention

The developer retains no user information because no information is sent to the developer. Local extension history remains in the user's browser until the user clears it or removes the extension.

Children's privacy

Downloaded media may contain children other than the account holder's child. Users are responsible for storing and sharing downloaded media appropriately and complying with their childcare centre's policies.

Changes

Any future change that introduces data collection or additional data sharing must be disclosed prominently before release and reflected in this policy.
